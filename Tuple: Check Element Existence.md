## EX.NO:3(E)	Tuple in Python: Check Element Existence
## AIM:
To Write a Python program to check whether an element 'n' ,'8’ exists within a tuple.

## ALGORITHM:

Step1: Input x is equal to some letters given in question 

Step2: Print n in x

Step3: Then print 8 in x 

Step4: Execute the program.

## PROGRAM:
```
x=("s", 8, "a", "v", "n", "g", "u", "r", "c", "e")
print("n" in x)
print(8 in x)
```
